## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/portfolio.git

# Navigate to project directory
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:3000` to see your portfolio in action!

## 🔧 Customization

### Update Content
1. Edit component files in `app/components/`
2. Update skills in Icon Cloud configuration
3. Modify terminal commands in Terminal component
4. Adjust grid layout in bento grid configuration

### Styling
- Tailwind config: `tailwind.config.ts`
- Global styles: `app/globals.css`
- Theme colors: Update in Tailwind config
